# TheAffluenceProjectHub

## Quick start

1. **Install dependencies** (once):

   ```bash
   npm install
   ```

2. **Run a local server**:

   ```bash
   npm run dev
   ```

3. Open **http://localhost:5173** in your browser. The hub is served from `index.html` (React/JSX is in the inline `<script type="text/babel">` block). Stop the server with `Ctrl+C`.

`index.jsx` is a separate source copy for editors; the live page uses `index.html` unless you add a build step.
